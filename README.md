# Code Manager v9.4

本地代码托管管理工具 - 支持 GitHub / Gitee 平台

## v9.4 修复内容

### 修复推送失败问题
- ✅ 修复本地分支 master 与远程分支 main 不匹配问题
- ✅ 初始化时自动将分支重命名为 main
- ✅ 推送前自动检测并重命名分支
- ✅ 处理合并冲突（使用 -X theirs 策略）
- ✅ 推送前先提交更改

### 使用流程（新项目）
1. 选择本地项目文件夹
2. 输入远程仓库地址
3. 点击"初始化并关联（一键）"按钮
4. 点击"提交并推送"按钮
